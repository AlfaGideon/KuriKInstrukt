# KuriK Instrukt — «Курьер Старт»

Мобильное приложение-инструкция: **как курьеру создать аккаунт в Яндекс Еде** — от требований и документов до первой смены. 7 шагов, чек-лист документов, сравнение форм сотрудничества и FAQ.

Интерфейс написан как PWA (HTML/CSS/JS без зависимостей) и упакован в нативный Android-контейнер (WebView), поэтому работает полностью офлайн.

> **APK:** [`dist/KuriK-Instrukt.apk`](dist/KuriK-Instrukt.apk) (~500 КБ, Android 7.0+, подпись v2).

---

## Что внутри приложения

| Экран | Что делает |
|---|---|
| **Шаги** | 7 шагов оформления с прогресс-кольцом: требования → документы → самозанятость → анкета → фотоконтроль → проверка → первая смена |
| **Шаг** | Подробный разбор: что делать, советы, частые ошибки, макет экрана приложения, ссылка на официальную анкету |
| **Документы** | Интерактивный чек-лист (13 позиций) + сравнение схем: НПД / ГПХ / парк |
| **Вопросы** | FAQ: медкнижка, возраст, иностранцы, выплаты, отказ по заявке |
| **Прогресс** | Сохраняется в `localStorage` устройства, сбрасывается кнопкой ↺ |

## Запуск веб-версии

```bash
python3 -m http.server 8080 --directory app
# открыть http://localhost:8080
```

Страница адаптирована под телефон; на десктопе показывается в рамке. Её можно «установить» как PWA (Safari: «На экран Домой», Chrome: «Установить приложение»).

## APK

Готовый файл: `dist/KuriK-Instrukt.apk`. Установка: разрешить «Установка из неизвестных источников» → открыть файл.

### Как он собирается

`.github/workflows/build-apk.yml` на каждый push в `main` или `arena/**`:

1. ставит JDK 17 и Android SDK (platform 34, build-tools 34);
2. собирает `android/` через Gradle `assembleRelease` (AGP 8.5, подпись — debug-ключ, поэтому годится для установки «с руки», но не для стора);
3. публикует `dist/KuriK-Instrukt.apk` обратно в репозиторий (коммит `[skip ci]`) и в артефакты workflow.

Локальная сборка (нужны JDK 17 + Android SDK + Gradle 8.7):

```bash
cd android
gradle assembleRelease
# результат: android/app/build/outputs/apk/release/app-release.apk
```

Gradle-таск `syncWeb` перед сборкой копирует `app/` в `android/app/src/main/assets/www/`, так что APK всегда содержит актуальную версию интерфейса.

Для публикации в Google Play замените `signingConfig` на собственный keystore (см. `android/app/build.gradle`).

## Структура

```
app/                       интерфейс (PWA, офлайн)
├── index.html             каркас: топбар, экран, таббар
├── styles.css             дизайн-система (светлая/тёмная тема, анимации)
├── app.js                 роутер на hash, рендер экранов, прогресс
├── data.js                весь контент: шаги, документы, формы, FAQ
├── manifest.webmanifest   PWA-манифест
├── sw.js                  service worker (офлайн-кэш)
└── icons/                 иконки

android/                   нативная обёртка
├── app/src/main/java/ru/kurik/instrukt/MainActivity.java
├── app/src/main/AndroidManifest.xml
└── app/build.gradle       syncWeb + release-сборка

.github/workflows/build-apk.yml
dist/KuriK-Instrukt.apk    собранный APK
```

Контент правится в `app/data.js` — код трогать не нужно.

## Дисклеймер

Приложение неофициальное и не связано с Яндексом. Условия сервиса, набор документов и требования отличаются по городам и могут меняться — актуальную информацию проверяйте на [eda.yandex.ru](https://eda.yandex.ru/rabota/kurer/).
